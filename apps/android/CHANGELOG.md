# Changelog

Phren for Android. Newest first. The app shows the section for its own version
once after an update ("What's new") and keeps the whole file under
Settings → About. The version is `versionName` in `app/build.gradle.kts`.

## 1.0.0

### New

- Phren for Android: the iPhone app's memory, agents and terminal on Android, with the same design, the same store format and the same sync.
- Projects, findings, notes, tasks and summaries, edited offline and synced to your GitHub store when you're back online.
- The Memory tab's graph is the same renderer the iPhone app, the web UI and the VS Code extension use.
