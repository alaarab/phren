Phren for iOS Privacy Policy

Effective 2026-07-28 · applies to the Phren iOS app (bundle id com.phren.ios)
Summary: this app doesn't collect any data. It has no analytics, no ads, and no third-party code. It connects to GitHub's API and nothing else, and your token stays in the device Keychain.

What the app is

Phren for iOS is a client for your own phren store, which is a git repository of markdown files that you host on GitHub. There is no Phren backend and no account with us. Your data never touches a server of ours, because we don't have one.

Data we collect

None. The app has no analytics, crash reporting, advertising, or tracking of any kind. We don't collect data, so there is nothing to sell or share.

Where your data lives

  • Your GitHub token is stored in the iOS Keychain on your device. It is only ever sent to api.github.com, to read and write your own repositories. Signing out deletes it.
  • Your store content (findings, notes, tasks) is cached on your device so the app works offline. Removing a store in Settings deletes the local copy, and so does deleting the app.
  • Demo mode runs entirely on your device with sample data and makes no network requests at all.

Network requests

The only network requests the app makes are to GitHub's REST API (api.github.com) over HTTPS, to sync the repositories you add. Your use of GitHub itself is covered by GitHub's privacy statement.

Changes

If this policy changes, the new version will be published at this URL with a new effective date. This page lives in the phren repository, so any change to it shows up in the git history.
