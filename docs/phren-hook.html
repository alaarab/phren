Install on each computer

You’ll need macOS or Linux, Node 20+, Herdr, SSH, and lsof. Run as the same user who runs your agents.

npx --yes @phren/cli@0.3.5 bridge install
npx --yes @phren/cli@0.3.5 bridge doctor

Herdr is what lets Phren Hook find your agents, read their conversations and type into them. Without Herdr the app still gives you memory and an SSH terminal (a shell, or an agent started in a project folder) that ends when the connection drops. Support for tmux without Herdr is planned; it does not work yet.

The installer adds a LaunchAgent on macOS or a systemd user service on Linux. It preserves other agent hooks and SSH keys, and backs up files it changes.

New to phren? Get started walks through the whole setup, including pairing.

  1. On the computer, run phren pair (or npx --yes @phren/cli@latest pair without a global install). It installs Phren Hook if needed and prints a QR code.
  2. In Phren, open Agents → Add computer → Scan pairing code. Can’t scan? Choose Enter code and type the address and code the terminal shows.
  3. Keep Tailscale connected on both devices for remote access. No public port or Funnel is needed.

Prefer to do it by hand? Under Add computer choose Enter details, copy the SSH authorization line into that computer’s ~/.ssh/authorized_keys, and verify the SSH fingerprint Phren shows. Existing recognized Phren keys are migrated by the installer.

Restart agents that were running before you installed Phren Hook, so they load its callbacks. In Codex, review Phren’s new callbacks in /hooks. Resume existing agents if needed to load the callbacks. The helper connects to agents you run; it doesn’t start a coding agent automatically.

Know what’s happening

Chat updates follow the agent’s transcript writes. Token counts come from the agent. Phren keeps an exact computer, server, workspace, tab, pane, and conversation identity before sending a message.

Codex and Claude permission requests can appear in chat while you’re watching that conversation. Requests without a supported callback, including choice questions, stay accessible through Phren’s terminal.

Maintain your connection

npx --yes @phren/cli@0.3.5 bridge status
npx --yes @phren/cli@0.3.5 bridge update
npx --yes @phren/cli@0.3.5 bridge rollback
npx --yes @phren/cli@0.3.5 bridge uninstall

Updates install the CLI version you invoke. Rollback restores the previous helper version. Uninstall removes the service and Phren callbacks while retaining local data and backups. Remove the phone’s SSH key to revoke access.

Having trouble? Run bridge doctor, confirm SSH and Herdr are running, and check the phone’s authorization line. On Linux, use journalctl --user -u phren-hook; macOS logs live at ~/.local/share/phren/bridge/service.log.
